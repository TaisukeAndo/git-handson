# Git ガチャ大会（Git ハンズオン用リポジトリ）

アプリ開発エージェント構築セミナー（session2）で、Git と GitHub の操作を体験するための練習用リポジトリです。

ルールは簡単です。**自分の番号のガチャを引いて、結果をみんなのボードに書き込み、PRでマージします。**
全員の PR がマージされるほど、チームの合計ポイントが増えてランクが上がります。
隣の人の PR は、**うそがないかを確かめてから**マージします。

## 体験すること

1. リポジトリを取得する（clone）
2. 自分用のブランチを作る
3. ガチャを引いて、結果を `gacha.txt` の自分の欄に書き、コミットして Push する
4. プルリクエスト（PR）を作る
5. 隣の人の PR をレビューする（ガチャの結果が本物か、確かめる）
6. 問題がなければマージする
7. 全員の結果を取得（Pull）して、チームのランクを見る

## 事前に必要なこと

- GitHub のアカウントがあり、Claude Code から GitHub を使える状態になっている（`gh auth status` で確認）
- 講師から、このリポジトリへの招待（collaborator）が届いている。GitHub の通知かメールから承認してください
  - 承認しないと、Push や他の人の PR のマージができません
- 講師から、自分の番号（1〜30）を教えてもらう

## ガチャのしくみ

`gacha.py` に番号を渡すと、その番号のガチャ結果が出ます。**同じ番号なら、いつ、誰が実行しても同じ結果**です。
だから、隣の人の番号で実行すれば、その人が書いた結果が本物かどうか確かめられます。

| レア度 | ポイント |
|---|---|
| ★1 | 1 |
| ★2 | 3 |
| ★3 | 5 |
| ★4 | 10 |
| ★5 | 30（めったに出ません） |

チームのランクは、合計ポイントで決まります。

| 合計ポイント | ランク |
|---|---|
| 10以上 | ブロンズ |
| 30以上 | シルバー |
| 60以上 | ゴールド |
| 100以上 | プラチナ（30人全員がそろったときの合計です） |

## 自分の欄

`gacha.txt` には、1番から30番までの欄があります。**自分の番号の欄だけ**を書き換えてください。
他の番号の欄を書き換えると、他の人の変更とぶつかります。

```
== 07番 ==
名前：（自分の名前）
ガチャの結果：（gacha.py の結果をそのまま）
ポイント：（gacha.py の結果をそのまま）
```

## 手順（Claude Code に依頼します）

作業用のフォルダ（`my-ai-agent` など）で Claude Code を開き、順に依頼してください。
Python が使えない場合は、Claude Code が案内します。

### 1. 取得して、ブランチを作る

```text
次のリポジトリをこのフォルダにcloneしてください。
https://github.com/TaisukeAndo/git-handson

cloneしたら、自分用のブランチ「gacha-（自分の番号）」を作成して切り替えてください。
例：7番なら「gacha-07」
```

### 2. ガチャを引いて、結果を書く

```text
git-handson フォルダで、自分の番号（番号は○○）を渡して gacha.py を実行してください。
出た結果を、gacha.txt の自分の番号の欄に、名前と一緒に書き足してください。
結果とポイントは、gacha.py の出力のとおりに書いてください。
他の番号の欄は変更しないでください。
書き足したらコミットして、GitHubにPushしてください。
```

### 3. PRを作る

```text
今のブランチの変更について、mainブランチ宛てのプルリクエストを作成してください。
タイトルには、何番がどんな結果を書き足したかを書いてください。
```

### 4. 隣の人のPRをレビューして、マージする

1. GitHub でこのリポジトリの PR 一覧を開き、隣の人の PR を開く
2. 「Files changed」で、変更された行を確認する
   - その人の番号の欄だけが変わっているか
   - 他の人の欄や、他のファイルが変わっていないか
3. **ガチャの結果が本物か確かめる。** Claude Code に、次のように依頼する

```text
mainブランチの gacha.py を、隣の人の番号（○○番）で実行してください。
そのPRの「ガチャの結果」と「ポイント」が、実行結果と一致しているか教えてください。
```

4. 一致していれば「Merge pull request」でマージする
5. **一致していなければ、マージしない。** PR の画面にコメントを書いて、どこが違うかを伝える
   - コメントは「Files changed」で行を選んで書くか、PR の下の入力欄に書く
   - 直してもらったら、もう一度確認してからマージする

### 5. 全員の結果を取得して、ランクを見る

```text
mainブランチに切り替えて、GitHubの最新の状態を取得（Pull）してください。
そのあと、ranking.py を実行して、結果を教えてください。
```

チームの合計ポイントとランク、上位5人が表示されます。
結果や点数が `gacha.py` と合っていない欄は、ポイントに数えられず、「確認が必要な欄」に出ます。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| Push できない（権限エラー） | collaborator の招待を承認したか。GitHub にログインしているか（`gh auth status`） |
| マージできない | PR の画面で、マージのボタンが押せる状態か。自分に書き込み権限があるか |
| 「競合（conflict）」と表示された | 自分の番号以外の欄を書き換えていないか確認し、講師に声をかける |
| ブランチ名が重なった | 自分の番号を入れたブランチ名にしているか確認する |
| `gacha.py` が動かない | Claude Code に、エラーの内容を伝えて相談する |
