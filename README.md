# Git ハンズオン用リポジトリ

アプリ開発エージェント構築セミナー（session2）で、Git と GitHub の操作を体験するための練習用リポジトリです。
全員が同じファイル `kansou.txt` を編集し、プルリクエスト（PR）を作って、隣の人の変更をマージします。

## このハンズオンで体験すること

1. リポジトリを取得する（clone）
2. 自分用のブランチを作る
3. 自分の欄を編集して、コミットし、GitHubにPushする
4. プルリクエスト（PR）を作る
5. 隣の人のPRの差分を確認して、問題がなければマージする
6. 全員の変更が1つのファイルに集まったことを確認する（Pull）

## 事前に必要なこと

- GitHubのアカウントがあり、Claude Code から GitHub を使える状態になっている（`gh auth status` で確認）
- 講師から、このリポジトリへの招待（collaborator）が届いている。GitHubの通知かメールから承認してください
  - 承認しないと、Push や他の人のPRのマージができません

## 自分の欄

`kansou.txt` には、1番から30番までの欄があります。講師から伝えられた番号の欄だけを編集してください。
**他の番号の欄は書き換えないでください**（書き換えると、他の人の変更とぶつかります）。

```
== 07番 ==
名前：（ここに自分の名前）
感想：（ここに今日の感想を1行）
```

## 手順（Claude Code に依頼します）

作業用のフォルダ（`my-ai-agent` など）で Claude Code を開き、順に依頼してください。

### 1. 取得して、ブランチを作る

```text
次のリポジトリをこのフォルダにcloneしてください。
https://github.com/TaisukeAndo/git-handson

cloneしたら、自分用のブランチ「edit-（自分の番号）」を作成して切り替えてください。
例：7番なら「edit-07」
```

### 2. 編集して、コミット・Push

```text
kansou.txt の（自分の番号）番の欄に、名前と今日の感想を1行書き足してください。
他の番号の欄は変更しないでください。
書き足したらコミットして、GitHubにPushしてください。
```

### 3. PRを作る

```text
今のブランチの変更について、mainブランチ宛てのプルリクエストを作成してください。
タイトルには、何を変更したかを書いてください。
```

### 4. 隣の人のPRを確認して、マージする

1. GitHubでこのリポジトリのPR一覧を開き、隣の人のPRを開く
2. 「Files changed」で、変更された行を確認する
   - 隣の人の番号の欄だけが変わっているか
   - 他の人の欄や、他のファイルが変わっていないか
3. 問題がなければ、「Merge pull request」でマージする

### 5. 全員の変更を取得する

```text
mainブランチに切り替えて、GitHubの最新の状態を取得（Pull）してください。
```

`kansou.txt` を開いて、全員の名前と感想が集まっていることを確認します。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| Pushできない（権限エラー） | collaboratorの招待を承認したか。GitHubにログインしているか（`gh auth status`） |
| マージできない | PRの画面で、マージのボタンが押せる状態か。自分に書き込み権限があるか |
| 「競合（conflict）」と表示された | 自分の番号以外の欄を書き換えていないか確認し、講師に声をかける |
| ブランチ名が重なった | 自分の番号を入れたブランチ名にしているか確認する |
